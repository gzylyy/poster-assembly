# Poster Assembly · 海报分块制作技能

[English](README.md) · **简体中文**

由 **Fishking** 维护的一套海报制作技能：规划构图、制作独立视觉素材，并提供可编辑排版所需的参数与操作指导。

它将构图决策、图像素材、文字排版和输出检查分别处理，便于只修改有问题的部分。

**完整示例：**[需求 → 布局 → 独立素材 → 拼接结果](examples/folded-light/README.md)。示例图形为本项目制作的可复现 SVG，明确区分演示与真实 AI 出图，不作为模型效果对比。

## 适合哪些任务

- 需要独立素材、局部特写、人工拼接的单张或系列海报。
- 生图前验证中文文案容量、阅读层级和版面留白。
- 保持同一产品身份，同时尝试不同背景、媒介或画风。
- 规划素材像素、裁切损耗、印刷尺寸及不同渠道的导出。
- 排查透视、光线、接触阴影与抠图边缘造成的拼接违和感。
- 整理素材提示词、摆放参数、修改记录及交付清单。

普通配图或单纯图片放大可直接使用对应工具，无需完整走本流程。

## 使用条件与交付范围

需要支持 `SKILL.md` 的智能体环境；实际生成或编辑图片的步骤，还需要会话中可用的图像工具。最终海报通常由用户在支持文字和图层编辑的设计软件中组装。

仓库提供指引、模板及矢量示例。图像模型、账号和生图额度由实际使用环境提供；尺寸、透明背景、费用和编辑能力均按当时可用工具核实。

## 在 Codex 中安装

下载仓库并解压，将其中的 **`skills/poster-assembly` 文件夹整体复制**到技能目录。个人安装后的主文件应位于：

```text
~/.agents/skills/poster-assembly/SKILL.md
```

Windows 的 `~` 指你的用户目录。`SKILL.md`、四份参考文档、`agents/openai.yaml` 和 `LICENSE` 应一起保留，不能只复制主文件。

如果只希望当前项目使用，可改放到项目的 `.agents/skills/poster-assembly`。选择一种安装范围，避免出现同名重复项。未显示新技能时重启宿主；具体扫描位置和不同宿主的操作参见 [官方技能文档](https://learn.chatgpt.com/docs/build-skills)。

仓库也包含供支持该格式的宿主使用的 [plugin.json](plugin.json)。本页说明的是直接安装技能文件夹；GitHub 托管本身不会自动把项目上架到插件市场。

## 快速开始

先进行不消耗生图额度的规划：

```text
使用 $poster-assembly，用中文回复。
我需要一张虚构纸艺展的屏幕海报，比例 2:3，导出 1200 × 1800 px。
配色为深蓝、暖白和橙色，请先给信息层级、素材清单与布局方案。
先不要生图，只追问会影响当前规划的关键缺项。
```

英文入口示例见 [English quick start](README.md#try-it)。有技能选择器的宿主，也可通过其界面选中已安装技能。

## 工作流程

| 阶段 | 主要产出 |
|---|---|
| 0. 澄清需求 | 复用已知需求，明确用途、关键缺项及已有授权 |
| 1. 规划布局 | 阅读顺序、真实文案容量、版式和素材清单 |
| 2. 确认构图 | 简单布局参考，确认后再进行高清制作 |
| 3. 制作素材 | 独立素材、细节核对、实际尺寸与能力限制 |
| 4. 指导拼接 | 坐标、裁切、蒙版、光影及图层参数 |
| 5. 排版交付 | 可编辑文字、输出检查和文件清单 |

已有适用且确认过的布局直接复用；已有工具与预算授权范围内继续执行。涉及新的范围，或用户要求逐步确认时，再处理相应决策。

## 是否需要全部换成英文

当前采用 **英文首页 + 完整中文说明 + 中文技能正文**。技能简介含中英文关键词，界面名称为英文；英文 README 提供独立可读的介绍和使用入口，但不会将中文正文冒称为完整英译版。

建议先维护一套权威规则，减少翻译版本不同步。使用时可以明确要求智能体用中文或英文回答，并先用上面的纯规划任务检查自己的宿主表现。英文正文的完整翻译可在有明确需求后补充，维护原则见 [语言与翻译说明](docs/LANGUAGE.md)。
