# Contributing / 参与改进

Small, concrete improvements are welcome. Keep the workflow focused on independently editable visual materials and a truthful handoff.

欢迎具体、可验证的改进。请保持“独立素材 + 可编辑排版 + 如实交付”的定位。

1. Describe the task and observed problem before changing a rule. / 先说明真实任务和问题，再修改规则。
2. Update the authoritative Chinese instructions under `skills/poster-assembly`; keep both READMEs consistent when user-facing behavior changes. / 中文技能正文为权威版本，用户可见行为变化时同步中英文说明。
3. Distinguish a requirement from a design suggestion. Preserve the user's existing brief and authorizations. / 区分必要条件与经验建议，保留用户已确认的需求和授权。
4. Check local links, file names, template consistency, and any affected numeric examples. / 核对链接、文件名、模板一致性及受影响的计算示例。
5. Exercise a realistic request and a nearby request that should not activate the skill. Report what was actually tested. / 用真实场景和一个不应触发的相近请求检查行为，如实说明验证范围。
6. For example changes, preserve editable SVG sources and distinguish designed demos from generated results. / 修改示例时保留可编辑源图，明确演示与真实生成结果。

For a bug report, include the host and version, a non-private brief, the relevant stage, expected behavior, and actual behavior. Reports and pull requests may be written in English or Chinese. / 问题反馈可使用中文或英文，包含宿主及版本、可公开的需求、阶段、预期和实际行为。
