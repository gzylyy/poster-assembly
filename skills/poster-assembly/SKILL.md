# 海报制作：规划、分块素材与人工排版

## 用途与边界

为参赛、展示、商用海报提供构图规划、独立图像素材和排版指导。默认由用户在 Photoshop、Illustrator 等设计软件中组装最终海报；先明确这一交付方式，不把素材图当作含完整排版的成品交付。

保留六个阶段，但按已有项目状态接续：需求澄清 → 布局规划 → 参考图确认 → 高清素材 → 人工拼接 → 文字与导出。用户已有经确认的布局或参考图时，核对其适用范围后直接复用，无需从头重走。

按项目规模选用检查项和模板，不为简单任务填写全部表格。设计与制作经验见 [视觉设计、素材衔接与交付](references/design-and-production.md)，只读取当前任务对应的小节。

## 核心原则

1. **复用已知信息**：先整理用户已提供的规格和授权，只询问会改变构图、成本或交付的缺项。非关键缺项可标明建议值；不反复询问已确认内容。
2. **先确认构图**：参考图获确认后再制作高清素材。工具使用授权与构图确认是两件事，不能相互替代。
3. **按素材拆分**：每个需要独立编辑的素材单独交付。整体场景可以包含多个有空间关系的对象；不把一张联系表或拼图当作多个独立高清素材。
4. **图文分离**：生成素材不承载最终标题、正文、数字、编号或标识；这些内容在后期以可编辑文字或矢量添加。用户提供的真实标识按原始文件使用，不由模型重绘。
5. **如实说明能力**：目标像素、工具支持尺寸与实际文件尺寸分别记录；不把超分辨率当作真实细节恢复，也不承诺图生图能保证结构正确。
6. **按授权推进**：尊重用户指定的工具、预算和确认节奏；已授权范围内连续执行，需要扩展范围时再确认。

## 阶段 0 · 需求澄清

先整理已知条件，再集中询问关键缺项，不机械地逐条盘问。

| 条件 | 确认内容 |
|---|---|
| 用途与规格 | 印刷、参赛或屏幕；比赛、客户或平台的原始要求 |
| 受众与目标 | 主要观看者、典型观看距离或设备，以及希望其首先理解或记住的内容；需要行动时再明确入口 |
| 数量与复用 | 单张或系列；张数；哪些版式、风格和元素需要共用 |
| 尺寸 | 印刷的成品物理尺寸，或屏幕的目标像素；长宽比是否固定 |
| 内容与风格 | 必须出现的主体、信息和文字；风格、主色及参考图 |
| 交付 | 独立素材与排版指导的范围、文件格式、截止时间 |
| 工具与费用 | 已指定和可用的工具；生成次数或预算；是否要求逐次确认 |

用户尚无风格方向时给出 2–3 个简短候选；用户明确请你决定时，提出建议并按其授权推进。不要擅自替换用户指定的风格。

印刷与屏幕规格的处理见 [画布与分辨率规划](references/canvas-and-resolution.md)。印厂或平台细则未定时，明确待确认项，可先推进不依赖这些细则的布局工作。

**产出**：已确认的条件、关键待确认项及明确标注的建议值。核心用途、数量、尺寸或构图方向尚不清楚时，先澄清再生成。

## 阶段 1 · 结构布局规划

使用 [模板](references/templates.md) 的区块清单，主动给出以下内容：

- 主视觉、信息区、局部特写和文字区的位置、占比及视觉动线。
- 先确定主要信息与阅读顺序，用真实文案或接近真实长度的可编辑占位文案试排；文案容量在布局阶段验证，不能等素材做完才发现装不下。视觉生成的参考图仍保持图文分离。
- 每个区块的来源：AI 生成、实拍、现有素材、矢量制作或人工排版，并说明选择理由。
- 需要后期移动、缩放的主体及其分层要求；提前决定是否需要透明背景。
- 已识别的内容冲突及取舍方案。精密结构、真实品牌和数据优先使用可核实的资料。

**单张**：提出布局方案后，按约定的审阅节奏制作参考图。用户要求先审布局时，获得确认后再生成。

**系列**：先定一张代表性的母版，明确共用项与可变项。用户要求统一的部分才统一；内容确实容纳不下时调整相应变体，并确认调整，不强行套版。

需要系列或分批制作时记录简短的视觉约定：主体身份、构图锚点、透视、光向、色彩及排版的共用范围。允许变化的画风和主色单独列出；不将“系列一致”误解为必须使用同一种画风。方法见 [视觉设计与制作经验](references/design-and-production.md)。

**产出**：区块清单与布局方案。可将布局和后续参考图合并为一次审阅，避免为相同决策重复确认。

## 工具选择与授权

在生成前检查当前实际可用的工具：是否支持参考图、编辑、透明背景、质量档位和所需尺寸。只声明可以核实的能力；无法指定的参数不写成已设置。

| 任务 | 选择依据 |
|---|---|
| 构图参考 | 优先简单线稿、色块或低保真预览；工具支持时降低质量或尺寸 |
| 场景与主体素材 | 有适用参考且工具支持编辑时用参考图引导；否则说明限制后选可行方式 |
| 局部特写 | 参考原主体、相机方向和真实细节资料，核对与整体的一致性 |
| 分辨率补救 | 检查原生像素、裁切损耗和最终显示尺寸，再决定重做、缩小或超分辨率 |
| 文字、结构线与标识 | 使用排版、矢量工具或原始文件，保留编辑能力 |

首次提出工具方案时说明：**工具名称、选择理由、计划用途与张数、已知费用或额度情况**。费用、耗时或剩余额度无法核实时明确说未知；不能把低保真外观当成低费用的证据。没有合适工具时交付布局、提示词和操作参数，说明哪些步骤尚未实际完成。

- 用户已授权同一工具和用途时，复用该授权；不因进入新阶段或再次调用就重复索要同意。
- 尚未授权生成时，先确认拟用方案；用户要求每次调用前确认时，按其要求执行。
- 更换到未授权工具、增加付费支出、超出约定张数或预算、安装插件或新增账号连接时，先确认新增范围。上传资料也须处于已有授权范围内。
- 没有工具偏好时给出一个可执行的推荐；仅在选择会明显影响效果或成本时提供备选，不强制用户比较多种工具。
- 失败后先判断原因，再做有针对性的修正。默认最多一次重试，且须包含在既有次数、费用授权内；未覆盖则先确认。仍失败时报告原因和替代方案，不循环出图。

## 阶段 2 · 低保真参考图（构图确认）

默认先做一张整版参考图，用线稿、灰模或色块确认分区、比例、视线和文字留白。工具无低价预览档时如实说明，可先用简单布局示意；不能虚称已降低生图费用。

- 参考图可包含多个场景对象；图中不生成文字、数字或序号，文字区用空白或占位块表达，区块说明放在图外。
- 用户要求对比时，按已授权的方案数逐一生成，每个方案单独交付，并说明比较维度；“默认一张”不限制已明确要求的多方案。
- 标明这是构图参考，不是高清成品；交付后等待用户确认，不提前生成高清素材。
- 参考图可供后续图像编辑或构图引导使用，其低清像素不直接充当高清成品。

系列的母版确认后，先明确后续推进范围：用户已批准同版式变体或批量推进时按授权执行；新构图、新视觉方向或超出母版的内容再提交对应参考图确认。

## 阶段 3 · 高清素材与局部特写

### 3.1 规划目标像素与生成顺序

按 [画布与分辨率规划](references/canvas-and-resolution.md) 反推素材尺寸，使用 [素材生成单](references/templates.md) 记录目标、来源和实际输出。

需要整体场景的海报，先制作并核对底图的空间关系，再做局部；以独立产品或拼贴为主的海报可直接制作独立素材，不强制额外生成一张整版高清底图。

布局参考负责分区和构图，真实照片、图纸或实物参考负责细节依据。选用图生图或编辑工具后仍需检查比例、透视与结构，不能用生成方式代替检查。

同类素材需要批量制作时，先完成并检查一份有代表性的素材，再沿用已验证的条件扩展；这是制作自检，不新增用户审批环节。严格要求同一产品型号或包装时，优先保留准确的原始主体，仅生成背景或辅助元素。

### 3.2 独立素材与局部特写

- 每份需独立使用的素材单独输出，保持合理裁切余量。
- 提示词分别写清主体身份、构图、视角、光照、材质、背景与需要保留的条件；实际尺寸和质量档位在工具参数中单独核实。可用 [素材提示词模板](references/templates.md)。
- 局部可用原图裁切作参考，结合细节资料生成或局部编辑；不要把裁切后放大视为新增真实细节。
- 核对同一主体在整体与特写中的形状、材料、颜色、结构、视角和光源。特写不应凭空增加与整体冲突的构件。
- 结构准确性无法验证时标注为概念或视觉示意；需要准确表达的结构改用图纸、实拍、CAD 或矢量重绘。
- 提前分离需独立移动的主体；已融合的图像优先检查能否选区、蒙版或局部编辑，不为局部调整重做全部素材。

### 3.3 验收与返工

检查实际尺寸、清晰度、残留文字、边缘、背景透明度，以及与已确认构图的一致性。超分辨率生成的纹理不作为真实结构证据。

分辨率不足时提供可行取舍：减小版面占比、换高质量素材、局部重做或经授权进行超分辨率处理，并记录处理后的实际尺寸。

**改变主要构图或视觉方向**时返回阶段 1–2 确认受影响的方案；调色、清边、局部修复或不影响版式的微调在当前阶段处理。

## 阶段 4 · 人工拼接指导

为每份素材提供可执行的交付参数：**文件名、实际尺寸、放置位置、推荐尺寸、裁切、透明度、色彩处理、叠放衔接及边缘处理**，使用 [交付参数单](references/templates.md)。

位置说明应包含画布基准和单位，例如以成品裁切框左上角为原点的 x、y、宽、高。没有测量依据时给出标注为建议值的参数，不伪造精确坐标。

每放入一个区块即可做临时拼接检查，及早发现比例、遮挡、光照和留白问题；素材齐备后再定稿。需要融入背景的边缘用蒙版处理；产品轮廓、结构线和刻意保留的硬边按设计保持清晰，不一律羽化。

素材显得“贴上去”时，先检查透视与尺度、光向、接触阴影和色温，再处理边缘与锐度，避免只靠加模糊掩盖问题。具体排查顺序见 [素材衔接经验](references/design-and-production.md)。

用户提供工作界面截图时，根据实际可见状态给出下一步操作；未查看的图层或设置不能当成已知事实。

## 阶段 5 · 文字、信息图与导出

在排版软件中制作标题、正文、数据、编号和引导线，核对文字、数据来源与阅读层级。品牌标识使用用户提供或可核实的原始素材。

中文排版检查行首行尾标点、断句、数字单位及字体缺字；长文优先调整信息分组与行宽，不以不断缩小字号解决全部容量问题。二维码使用可靠的原始码或由已确认内容编码生成，不交给生图模型绘制；按实际输出检查边界、可扫描性及目标内容。

保留可编辑文字和矢量源文件。导出位图时文字也会被栅格化，因此仍须检查最终像素和实际阅读尺寸；需要保持矢量时检查 PDF 等输出设置与字体处理。

按交付要求核对尺寸、色彩配置、出血、透明度和文件格式。印刷色彩与屏幕像素规则见分辨率参考；最终自检见 [各阶段检查清单](references/stage-checklists.md)。

横竖版或不同渠道先分别重排，再按各自规格输出；不默认拉伸或直接居中裁切。交付时区分源文件、独立素材、审阅预览与正式输出，提供版本和文件清单。核查最终导出文件；未实际完成的扫码、字体预检或源文件打包明确列为待完成。
