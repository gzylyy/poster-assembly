# 各阶段自检清单

这些项目供执行者自检，不是必须逐条向用户提问的问卷。已有规格、授权和确认应复用；未适用项标记“不适用”并注明理由。

## 阶段 0 · 需求澄清

- [ ] 已整理用户给出的需求，仅追问会影响构图、成本或交付的关键缺项。
- [ ] 单张或系列、张数、共用项和可变项已明确。
- [ ] 已区分屏幕像素规格与印刷物理尺寸，明确哪些印厂或平台要求尚待确认。
- [ ] 主题、必需内容、风格方向及参考素材已明确；用户授权代为选择时已记录建议。
- [ ] 已根据现有需求明确主要受众、观看条件及最优先传达的信息，未给所有海报强加营销入口。
- [ ] 已明确本次交付是素材与排版指导，并记录格式和时间要求或建议值。
- [ ] 已整理工具偏好、使用授权、预算或张数限制，以及是否需要逐次确认。

## 阶段 1 · 结构布局规划

- [ ] 区块清单包含内容、来源、位置和占比，文字区留白已考虑。
- [ ] 已用真实或接近真实长度的文案试排，验证阅读顺序与内容容量；占位文案已标明。
- [ ] 已给出视觉动线与布局理由；内容冲突有可选取舍。
- [ ] 可验证结构、品牌和数据有可靠资料来源或明确待补项。
- [ ] 可移动主体的分层、背景和透明度要求已提前规划。
- [ ] 系列母版的共用范围已明确；已有适用布局已复用。
- [ ] 需要时已记录主体身份、光向、透视和排版约定，区分必须一致与允许变化的条件。
- [ ] 布局审阅与参考图审阅的安排清楚，没有为同一决策重复确认。

## 工具与费用（生成或编辑前核对）

- [ ] 已核实当前可用能力，没有虚构模型、插件、质量档位或输出尺寸。
- [ ] 拟用工具、用途、张数与已知费用已说明；未知费用未编造。
- [ ] 本次操作在已有授权范围内；超范围的工具、费用、连接或上传已获确认。
- [ ] 已有授权没有被无故重复询问；用户要求逐次确认时已遵守。
- [ ] 失败重试有具体修正依据，并在约定次数与费用范围内；默认重试不超过一次。

## 阶段 2 · 低保真参考图

- [ ] 默认一张；用户批准的多方案按约定数量和比较维度制作，每版单独交付。
- [ ] 用线稿、灰模、色块等表达构图，没有把低保真外观虚称为低费用。
- [ ] 图中没有生成文字、数字或编号，文字区用留白或占位块表示。
- [ ] 已说明这是构图参考，后续可作引导，但不会直接沿用其低清像素为高清成品。
- [ ] 用户已确认适用参考图后才进入高清制作；工具授权未被误当成构图确认。
- [ ] 系列逐张确认还是按母版批量推进已有约定，现有授权已复用。

## 阶段 3 · 高清素材与局部特写

- [ ] 已分别记录目标规格、工具能力与实际输出，考虑比例和裁切损耗。
- [ ] 需要整体场景时先检查整体，再处理局部；不需要底图时没有额外生成。
- [ ] 每份独立素材有单独文件，整体场景可合理包含多个有关联的对象。
- [ ] 批量制作先检查了代表性素材；需准确保留型号或包装时优先使用可靠原始主体。
- [ ] 布局参考与真实细节参考的用途已区分；图生图结果仍检查了结构和透视。
- [ ] 整体和特写的形状、材质、视角、结构及光源一致，没有用放大结果充当事实依据。
- [ ] 缺少可验证依据的结构已标注示意；用户要求结构准确时，须补充可靠资料或改用有依据的表达，不能以示意替代准确性验收。
- [ ] 图中无残留生成文字，实际像素、背景、透明度和边缘符合交付要求。
- [ ] 主要构图变化已返回规划或参考图确认；局部修复未被迫重走全流程。

## 阶段 4 · 人工拼接指导

- [ ] 每份素材有文件名、实际尺寸、放置位置、推荐尺寸和裁切说明。
- [ ] 透明度、色彩、叠放衔接和边缘处理已说明；坐标基准和单位明确。
- [ ] 临时拼接用于及早检查比例和遮挡，素材齐备后再定稿。
- [ ] 需融合的边缘已指导蒙版处理；设计要求保留的清晰轮廓未被一律羽化。
- [ ] 已按实际图像排查尺度、透视、受光、接触阴影、边缘污染与锐度，而非只靠模糊补救。
- [ ] 截图指导基于已看到的界面，未假定未知图层和设置。

## 阶段 5 · 文字、信息图与导出

- [ ] 文字、数字、编号和线条用排版工具制作；内容与可靠来源核对。
- [ ] 中文标点、断行、缺字、中英文混排与长文可读性已检查，未靠拉伸或无限缩小字号塞版。
- [ ] 使用准确的原始标识，并保留可编辑文字、矢量及图像源文件。
- [ ] 屏幕导出核对实际像素、格式和阅读尺寸，未以 PPI 标记代替清晰度检查。
- [ ] 印刷交付核对成品尺寸、含出血尺寸、安全区和有效 PPI，按实际要求设置。
- [ ] 色彩模式、嵌入配置文件与转换方式符合平台或印厂要求，没有一律转 CMYK。
- [ ] 已检查位图栅格化或 PDF 的矢量、字体处理结果。
- [ ] 多画幅已按内容重排，未拉伸主体或误裁必需信息；预览与正式输出用途明确。
- [ ] 有二维码时已核对码源、适用码制的留白及实际输出下的扫码和目标内容；未执行项标记待验证。
- [ ] 需移交时已列版本和文件清单，核对链接、字体、文字溢出及最终导出；未覆盖已确认源文件。
- [ ] 已说明哪些素材或导出文件实际完成，哪些仍需用户在设计软件中操作。
