# 项目与交付模板

按需要填写，已有值直接复用；不适用项标明原因。未知值标记“待确认”或“未知”，建议值标明“建议”，不编造实际输出、费用或用户授权。

## 模板 1 · 区块清单

位置坐标以约定画布为基准，可用像素、毫米或百分比；宽度占比与高度占比分别记录。

| 区块 / 素材 ID | 内容 | 制作方式 / 来源 | 位置与宽高占比 | 是否独立图层 |
|---|---|---|---|---|
|  |  |  |  |  |

制作方式可填 AI 生成、矢量制作、实拍、现有素材或人工排版。文字区注明留白与后期排版方式，不安排模型生成文字。

## 模板 2 · 素材生成单（每份独立素材一份）

```text
项目 / 海报编号：
素材 ID / 名称：
对应区块与用途：
已确认的布局 / 参考图：
目标放置区域与尺寸：
素材目标像素：
裁切比例与所需余量：
细节依据：                  真实照片 / 图纸 / 概念示意等
生成方式：                  文生图 / 参考图编辑 / 局部重绘等
拟用工具及可核实能力：
工具支持的输出尺寸与格式：
实际请求参数：              不可配置项不要填写为已设置
本次张数与已知费用：        无法核实时写未知
已有授权及范围：            工具、用途、张数 / 预算、确认节奏
整体与特写需保持的关系：    形状、材质、结构、视角、光源
背景与图层要求：            透明 / 纯色 / 实景；是否独立图层
输出内容要求：              无生成文字、数字、编号或重绘标识
实际交付文件及像素尺寸：    完成后据实填写
后处理与验收结果：          如裁切、超分辨率、清边及剩余限制
```

工具授权不代表构图已确认；这两项分别记录。参考图裁切可作局部引导，不能据此声称新增细节真实准确。

## 模板 3 · 素材交付参数单

```text
项目 / 海报编号：
素材 ID / 文件名：
文件格式与实际像素：
色彩空间 / 嵌入配置文件：
背景及实际透明度：
画布基准：                  成品裁切框 / 含出血画布；尺寸与单位
坐标原点：                  如左上角
放置位置 x / y：
推荐放置宽 / 高：
裁切范围与缩放方式：
图层透明度 / 混合方式：
色彩处理：                  色温、饱和度、明度关系
叠放与衔接：                层序、遮挡、光照、阴影
边缘处理：                  需融合处蒙版；需清晰处保留轮廓
有效 PPI：                  印刷适用，结合实际放置与裁切计算
仍需用户完成的操作：
```

未经实际测量的坐标、裁切和处理参数标为建议值，不假称已在用户文件中应用。

视觉约定：                  主体身份、构图锚点、光向、透视、排版共用项
允许变化的视觉条件：        主色、媒介、背景或其他已授权变化

项目参数随当前任务传递，不把单个项目的尺寸、工具、预算或风格写成技能的通用规则。
