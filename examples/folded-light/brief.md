# Example brief / 示例需求

## Confirmed for this demonstration / 本演示的设定

| Item / 项目 | Decision / 设定 |
|---|---|
| Purpose / 用途 | Screen-only fictional paper-art exhibition study / 虚构纸艺展的屏幕设计演示 |
| Audience / 受众 | Visitors skimming a project page / 浏览项目页面的读者 |
| First impression / 第一印象 | Folded paper, light, and a clear headline / 折纸形态、光影与明确标题 |
| Quantity / 数量 | One composition plus a text-free layout reference / 一张排版结果及无字布局参考 |
| Canvas / 画布 | 1200 × 1800, 2:3 |
| Artwork / 图形 | An abstract folded-paper form; no real product identity or structural claim / 抽象纸雕，不对应真实产品或构造 |
| Palette / 配色 | Deep blue `#102A36`, warm paper `#F1EDDF`, orange `#E86B3C` |
| Lighting / 光线 | Soft upper-left light with folded faces and a contact shadow / 左上柔光、折面与接触阴影 |
| Typography / 文字 | Editable text using generic system serif and sans-serif fallbacks / 可编辑文字，使用系统衬线与无衬线回退 |
| Generation / 生成 | Original SVG authoring and deterministic raster export; no image-model call / 自制 SVG 与确定性位图导出，未调用生图模型 |
| Delivery / 交付 | Brief, layout, two independent assets, editable final SVG, PNG previews / 需求、布局、两份独立素材、最终 SVG 和 PNG 预览 |

## Acceptance / 验收

The title remains the leading reading element. Artwork files contain no text. The final keeps the hero's aspect ratio, uses the supplied source geometry, and leaves copy editable. The hero export has genuine transparency. No real event date, venue, URL, QR code, or image-generation performance is invented.

标题是主要阅读入口；图形素材无字；最终结果沿用源图形并保持主体比例；文字可编辑；主体导出具有真实透明背景。不编造真实活动、二维码或模型性能。
